موقع ترف العقارية — ملفات جاهزة للنشر على Cloudflare Pages

الصفحات:
- index.html: الرئيسية
- lands.html: الأراضي
- villas.html: الفلل
- contact.html: التواصل ونموذج يفتح واتساب برسالة جاهزة
- assets/style.css: التصميم والتجاوب مع الجوال

النشر:
1) فك ضغط الملف ZIP.
2) افتح Cloudflare Dashboard ثم Workers & Pages ثم Create application ثم Pages.
3) اختر Upload assets / Direct Upload (قد يختلف الاسم حسب واجهة Cloudflare).
4) ارفع محتويات المجلد (وليس ملف ZIP إن طلبت الواجهة ملفات الموقع).
5) أكمل النشر.

تعديل رقم واتساب:
استبدل الرقم 966500000000 في ملفات HTML برقمك بصيغة دولية، أرقام فقط، بدون + أو مسافات.
مثال: 9665XXXXXXXX

تعديل البريد:
استبدل hello@taraf-realestate.example بالبريد الحقيقي.

تنبيه مهم:
- الهاتف والبريد وبيانات العقارات والأسعار الحالية وهمية/تجريبية.
- الصور من روابط Unsplash وتحتاج اتصال إنترنت.
- الخطوط من Google Fonts.
- لا يوجد نظام إدارة عقارات أو قاعدة بيانات أو حفظ طلبات؛ نموذج التواصل يرسل تفاصيله إلى واتساب فقط.
- راجع التراخيص والبيانات النظامية والإعلانات العقارية قبل نشر عروض فعلية.
